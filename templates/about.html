About G8BikeShare

G8BikeShare is a Dublin bike-sharing web application designed to make city cycling easier and more informed. It combines live station availability, current weather, forecast trends, journey support, historical bike patterns, and AI-powered riding advice in one interface.

Project overview

The goal is to improve the Dublin Bikes experience by going beyond raw station data. Rather than only showing how many bikes are available, G8BikeShare helps users understand whether a station is practical right now, whether the weather is suitable for riding, and how to move quickly into route planning.

Key features

Everything built into a single cycling companion for Dublin.

🗺️

Live station map

Explore markers on Google Maps with real-time bike counts, dock availability and station status.

🌤️

Weather-aware cycling

Live conditions and forecast charts help you decide if conditions are suitable before borrowing a bike.

🧭

Journey planner

Built-in navigation tools move you from station discovery to Google Maps cycling directions in one click.

📈

Historical trends

The dashboard shows 48-hour occupancy patterns so you can identify reliable stations over time.

💡

Ride Assistant

A rule-based assistant gives instant practical suggestions based on station availability and live weather.

🤖

AI Bike Assistant

An AI assistant answers natural-language questions about borrowing, returning, weather, and service usage.
