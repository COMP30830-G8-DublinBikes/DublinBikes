About G8BikeShare

G8BikeShare is a Dublin bike-sharing web application designed to make city cycling easier and more informed. It combines live station availability, current weather, short-term forecast trends, journey support, historical bike patterns, and both rule-based and AI-powered riding advice in one interface.

Project overview

The goal of this project is to improve the experience of using Dublin Bikes by going beyond raw station data. Instead of only displaying how many bikes are available, G8BikeShare helps users understand whether a station is practical right now, whether the weather is suitable for riding, where to return a bike, and how to move directly into route planning with less friction.

Key features

Live station map

Users can explore station markers on Google Maps and immediately inspect available bikes, available docks, and station status.

Weather-aware cycling

The site displays live weather and forecast graphs so users can decide whether conditions are suitable for riding before they borrow a bike.

Journey support

Built-in navigation and journey planner tools help users move from station discovery to route planning quickly.

Historical trends

The dashboard visualises recent bike occupancy patterns so users can identify useful stations over time rather than at only one moment.

Ride Assistant

A rule-based assistant gives immediate practical suggestions based on current station availability and live weather.

AI Bike Assistant

An AI assistant can answer natural-language questions about borrowing, returning, weather conditions, and service usage in a more flexible conversational way.
